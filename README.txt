ПУЛЬС — бета-прототип устанавливаемого веб-приложения (PWA), интерфейс полностью на русском языке.

УСТАНОВКА НА ANDROID:
1. Распакуйте архив на компьютере.
2. Опубликуйте содержимое папки PULSE на HTTPS-хостинге. Подойдёт GitHub Pages или другой статический хостинг.
3. На Android откройте адрес сайта в Chrome.
4. В меню браузера выберите «Установить приложение» или «Добавить на главный экран».
5. После установки ПУЛЬС будет открываться отдельным окном. Базовые страницы доступны офлайн после первого открытия.

ЧТО РАБОТАЕТ:
- Главная страница и русскоязычная навигация.
- Дневник приёмов пищи с категориями: завтрак, второй завтрак, обед, полдник, ужин, перекус.
- Справочник из 30 типовых продуктов с ориентировочной энергетической ценностью.
- Ручное добавление продукта, массы и значения с упаковки; расчёт оценки для порции.
- Программы на 30 дней: общая подготовка, подвижность, силовая основа, выносливость; три уровня; дни восстановления; отметки.
- Библиотека базовых упражнений с описаниями.
- 1000 оригинальных сочетаний мотивационных фраз и избранное.
- Отметки привычек и воды.
- Профиль, локальное сохранение, экспорт и импорт резервной копии.

ВАЖНЫЕ ОГРАНИЧЕНИЯ:
- Это бета, а не готовый медицинский или профессиональный фитнес-продукт.
- Справочник питания небольшой; автоматического распознавания еды по фото/штрихкоду пока нет.
- Энергетические значения ориентировочные. Приложение не назначает нормы калорий, дефицит или цели снижения веса; особенно важно не использовать подсчёт для ограничения питания у подростков.
- Программы тренировок демонстрационные и требуют проверки тренером перед массовым использованием.
- Данные хранятся локально в браузере на устройстве. Очистка данных браузера может их удалить; используйте резервную копию.
- Для установки PWA требуется HTTPS-хостинг. Этот архив сам по себе не является APK.
